## About

VOID RUNNER is built using **HTML5 Canvas** and vanilla JavaScript. It features:

- Pixel-perfect rendering at a base resolution of 320x180  
- Dynamic enemy spawning with basic AI  
- Combo scoring system  
- Particle effects for action feedback  
- Camera shake for impact effects  
- LocalStorage-based high score tracking  

---

## Gameplay

- Survive as long as possible while dodging enemies.  
- Each enemy collision reduces your HP.  
- Score increases over time, multiplied by combo streaks.  
- Dash to move faster and shake the camera, but cooldown applies.  
- Game ends when HP reaches zero.
